Grocery List — Trial Copy

Mr.E and Mrs.E • A trial copy of the shared grocery list with movable items. The original list is untouched.

Trial version: check an item and it drops to the bottom of its store list, and the list re-sorts alphabetically. Use ↑ ↓ to nudge an item, ✕ to remove it, and the boxes under each store to add new items. Changes are saved on this device only for the trial — they do not sync to the original shared list.

How this trial works

  • → Check the box when an item is bought — it moves to the bottom and the list re-sorts A–Z.
  • → ↑ and ↓ move an item one step; that order holds until the next check or uncheck re-sorts the list.
  • → ✕ removes an item. The add boxes under each store add new items.
